# Personal Portfolio Website — HTML & CSS

## 📌 Overview

This project is a personal portfolio webpage created as part of a homework assignment. The website was developed using **HTML and CSS**, with the help of **Prompt Engineering** to generate, refine, and improve the webpage structure and styling.

The purpose of this project is to demonstrate how AI-assisted development and effective prompt engineering can be used to create a functional and visually appealing webpage while understanding the underlying HTML and CSS concepts.

## 🎯 Objectives

- Create a personal portfolio webpage using HTML and CSS.
- Understand the basic structure of a webpage.
- Apply CSS for layout, styling, colors, typography, and responsiveness.
- Use Prompt Engineering to assist in generating and improving the website.
- Learn how AI can be incorporated into a basic web-development workflow.

## 🛠️ Technologies Used

- **HTML5** — Structure and content of the webpage.
- **CSS3** — Styling, layout, animations, and visual design.
- **Prompt Engineering** — Used to generate and refine HTML/CSS code with AI assistance.
